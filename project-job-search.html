1. The Engineering Challenge: Beating the ATS Black Hole

          

            Traditional job boards rely on keyword matching algorithms that penalise non-standard resumes and obscure true engineering competency behind recruiter buzzwords. Candidates spend hours tailoring applications manually for Applicant Tracking Systems (ATS), resulting in low response rates and severe fatigue.
          

          

            JOB SeArCh re-architects this process through geometric vector spaces. Instead of keyword searching, candidate skill profiles and live job descriptions are encoded into high-dimensional semantic vectors using 768-dimensional FastEmbed models.
          

        


        

          
2. The 5 Architectural Pillars

          

            

              

                
1. Latent Space Projection

                768-D HNSW
              

              
Projects resumes and candidate achievements into the same mathematical space as scraped job requirements, executing sub-20ms cosine distance searches.

            

            

              

                
2. Grok LLM Reasoning

                High-Throughput
              

              
Filters top semantic candidates, evaluates nuance (remote flexibility, senior vs staff scope), and synthesises personalised recruiter pitches tailored to each company.

            

            

              

                
3. Headless ATS Extraction

                Ashby · Lever · GH
              

              
Asynchronous extraction engines parse salary distributions, equity details, and requirement clauses from dynamic client-rendered career pages.

            

            

              

                
4. Zero-Knowledge RAM Vault

                Zero Storage
              

              
User credentials and personal tokens reside strictly in volatile browser RAM. Once the session ends or browser tab is closed, all traces are instantly discarded.

            

          

        


        

          
3. Security & Privacy: Zero-Knowledge Invariants

          

            Because automated job search engines frequently handle sensitive candidate data (phone numbers, addresses, salary expectations, LinkedIn tokens), JOB SeArCh enforces strict security invariants:
          

          
    
            
  • ✔ Ephemeral Memory: All user profiles are loaded into Flutter BLoC state streams and cleared on unmount.
    • 
            
  • ✔ Anti-SSRF Protection: Outbound scraping requests through the Python backend validate destination IP ranges, blocking private IPv4/IPv6 loopbacks (`127.0.0.1`, `169.254.169.254`).
    • 
            
  • ✔ 1-Click Portal Autofill: Secure DOM injection assists candidate applications on external portals without storing credentials on third-party servers.
