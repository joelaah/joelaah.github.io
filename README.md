## 🚀 Flagship Engineering Showcases

### 1. 🛡️ Compliance Checker — Audit Engine & Client-Side SAST
- **Multi-Framework Governance**: Evaluates codebases and cloud configurations against **SOC 2 Type II**, **ISO/IEC 27001:2022**, **HIPAA Security Rule**, and **GDPR Article 32**.
- **Zero Cloud Egress**: In-browser AST parser and Shannon entropy heuristics detect hardcoded secrets and misconfigurations strictly in Web Workers. Zero source code or credentials ever leave the client.
- **Auditor Exports**: Automatically calculates risk-weighted compliance readiness scores and generates structured remediation blueprints.

### 2. ⚡ PulseFit AI — Two-Stage RAG Fitness Copilot
- **Deterministic Math Engine**: Decouples tonnage and progressive overload calculations into pure Python microservices, eliminating **100% of LLM arithmetic hallucinations**.
- **Sub-15ms Vector Recall**: Qdrant Cloud HNSW indexing across 768-dimensional Gemini embeddings combined with **Cohere cross-encoder reranking** (filtering 25 candidates to top 3).
- **Offline-First Resilience**: Flutter Web client with instant HTML5 `localStorage` persistence and asynchronous cloud synchronization via Supabase anonymous JWTs.

### 3. 🎯 JOB SeArCh — Autonomous Career Matching Engine
- **Shared Latent Space**: Projects candidate profiles and live job descriptions into a 768-dimensional latent vector space using Supabase `pgvector` HNSW cosine indexing.
- **Ultra-Fast Inference**: Grok LLM integration for contextual alignment, custom outreach pitch generation, and role steering.
- **Headless ATS Scraper & RAM Vault**: Multi-platform scraping for Ashby, Greenhouse, Lever, and custom portals with a zero-knowledge client-side RAM credential vault for 1-click autofill.

## 💻 Local Development

Run the portfolio locally using any standard static file server:

```bash
# Clone the repository
git clone https://github.com/joelaah/joelaah.github.io.git
cd joelaah.github.io

# Using Python 3
python -m http.server 8000

# Or using Node.js
npx serve .
```

Open `http://localhost:8000` in Microsoft Edge, Chrome, Safari, or your preferred browser.
