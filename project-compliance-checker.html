1. The Engineering Challenge: The Cloud Privacy Paradox

Modern continuous compliance tools (Vanta, Drata, Snyk) frequently require granting broad read permissions across internal private Git repositories or shipping raw source code to external SaaS backend endpoints for vulnerability scanning. For enterprise security teams, defence contractors, and healthcare organisations handling protected health information (PHI), this creates an unacceptable cloud privacy paradox: shipping secrets to the cloud to check if secrets are in the cloud.

Compliance Checker was architected to resolve this paradox by moving the entire static application security testing (SAST) and audit policy evaluation engine directly into the client browser via Web Workers.

2. Multi-Framework Mapping Matrix

The engine standardises compliance checks across four foundational regulatory standards into unified deterministic rules:

SOC 2 Type II

Trust Services

Evaluates Common Criteria (CC6.1 Logical Access, CC6.6 Boundary Defense, CC6.8 Threat Detection, CC7.1 Vulnerability Management) against application configuration files and infrastructure code.

ISO/IEC 27001:2022

Information Security

Enforces Annex A controls (A.8.24 Use of Cryptography, A.8.28 Secure Coding, A.8.9 Configuration Management) with deterministic checks for hardcoded credentials and cipher choices.

HIPAA Security Rule

45 CFR Part 164

Validates technical safeguards (§ 164.312(a)(1) Access Control, § 164.312(c)(1) Integrity, and § 164.312(e)(1) Transmission Security) ensuring end-to-end payload encryption and session timeouts.

GDPR Article 32

Data Protection

Audits pseudonymisation, data minimisation, and AES-256 client-side at-rest storage invariants before database synchronization.

3. In-Browser AST & Shannon Entropy Secret Detection

Detecting credentials without false positives requires more than naive regex patterns. Compliance Checker implements a two-stage analysis pipeline:

  1. Abstract Syntax Tree (AST) Tokenization: Code is tokenised into AST nodes inside an isolated Web Worker, distinguishing string literals from comments, identifiers, and variable assignments.
  2. Shannon Entropy Calculation: String literals exceeding 20 characters are evaluated for information entropy: $$\mathcal{H}(X) = -\sum_{i=1}^{n} P(x_i) \log_2 P(x_i)$$ Strings with Shannon entropy \(> 3.4\) coupled with token signatures matching AWS keys (`AKIA...`), GitHub PATs (`ghp_...`), JWTs, or private RSA headers are flagged instantly with zero network transmission.

4. Key Production Features

  • ✔ Interactive Scoring Gauge: Real-time 0–100 audit readiness score updated dynamically as policies are verified.
  • ✔ Prioritized Remediation Blueprints: Step-by-step code patches and config snippets to resolve compliance gaps before external audits.
  • ✔ Auditor-Ready PDF & JSON Export: Timestamped reports formatted for direct submission to external SOC 2 and ISO compliance auditors.
  • ✔ Zero Network Egress Guarantee: Built with zero tracking scripts, telemetry beacons, or external API endpoints.
