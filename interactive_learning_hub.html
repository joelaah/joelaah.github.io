How Qdrant HNSW Works

Exact k-Nearest Neighbors ($k\text{-NN}$) requires an $O(N)$ brute-force comparison across millions of vectors—unviable in production. HNSW builds a multi-layer graph reminiscent of a skip-list:

  • Top Layers (Expressway): Sparse graph with long-distance edges. The query vector takes large spatial jumps to find the immediate neighborhood.
  • Layer 0 (Ground Mesh): Dense clustered graph containing every data vector. The search terminates with greedy local beam exploration.
  • Single-Stage Payload Filtering: Unlike naive databases that filter after search (breaking recall), Qdrant checks boolean payload constraints during the graph walk.

FastAPI Async Lifecycle

FastAPI combines Starlette's high-speed ASGI event loop with Pydantic's Rust-compiled data validation:

  • Async Non-Blocking I/O: Network calls to Qdrant Cloud and Postgres are awaited via asyncio, yielding the single-threaded CPU loop to serve concurrent requests.
  • Threadpool Offloading: CPU-bound tasks (deterministic volume math, tokenization) run in threadpool executors so the event loop never freezes.
  • Strict Type Coercion: Pydantic v2 enforces mathematical invariants before any business logic executes, eliminating undefined runtime crashes.

The Mathematics Behind Vector Recall

In high-dimensional embeddings (768 dimensions), text documents of different lengths generate vectors with dramatically different magnitudes:

  • Why Euclidean Distance ($L_2$) Fails: A 10-word summary and a 500-word article about the same topic have huge Euclidean distance simply because one vector is longer.
  • Why Cosine Similarity Wins: $\cos(\theta) = \frac{u \cdot v}{\|u\| \|v\|}$ isolates pure angular orientation, ignoring length completely.
  • The $L_2$ Normalization Trick: If every vector is pre-normalized to unit magnitude ($\|u\| = 1$), the denominator becomes $1$. Cosine search converts into a simple hardware Dot Product executed in AVX-512 SIMD assembly.

import numpy as np

def l2_normalize(vec: np.ndarray) -> np.ndarray:
    norm = np.linalg.norm(vec)
    return vec if norm == 0 else vec / norm

# With unit vectors, Cosine Distance is 1.0 - dot_product
u_norm = l2_normalize(embedding_query)
v_norm = l2_normalize(embedding_document)
cosine_distance = 1.0 - np.dot(u_norm, v_norm)

Why Two Stages Outperform Single-Stage

Naive RAG queries a bi-encoder directly into an LLM context window. PulseFit AI and JOB SeArCh decouple the workload:

  • Stage 1 (High Recall): Qdrant HNSW casts a wide net, retrieving 25 candidates in sub-15ms. Bi-encoders are fast ($O(1)$) but miss cross-token attention.
  • Stage 2 (High Precision): Cohere Cross-Encoder computes joint attention between the query and all 25 candidates, filtering down to the Top-3 with relevance scores $> 0.65$.
  • -85% Token Reduction: Compressing prompt size cuts Time-To-First-Token (TTFT) by 4x and eliminates attention degradation in the LLM.
  • Deterministic Mathematical Shield: Physical volume totals are computed in Python and injected as read-only facts—eliminating 100% of arithmetic hallucinations.
